# Business-Insights-360-AtliQ-Hardware_Project
Business Insights 360 is an interactive **Power BI business intelligence dashboard** developed for AtliQ Hardware to provide a comprehensive view of business performance across **Finance, Sales, Marketing, and Supply Chain** departments.

The project integrates data from **Excel/CSV files and a MySQL database**, followed by data cleaning, transformation, and data modeling in Power BI. The dashboard enables users to analyze key business KPIs, financial performance, sales trends, profitability, regional performance, and segment-level insights through interactive reports and visualizations.
